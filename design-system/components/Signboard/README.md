# Signboard

A green Indian highway direction sign: only for what lies ahead on the road.

**Provide:** an arrow svg (`__arrow`), the destination (`__dest`, ≤2 words), a sub-line, and an optional corner tag ("NEXT"). Use an `<a>` when it links.

**Rules**
- `signboard` fill, `on-signboard` text and the 2px inset border, `radius-soft`. Barlow Condensed uppercase, like real signs.
- Only three on the site: "Wispr Flow · India · Growth" at stop 10, "Mountains · A small café · someday" at the road's end, and optionally one in the garage.
- Arrow up means straight ahead (the next stop); arrow right means beyond the road.
- Never use it as a generic button or for past stops.
