# MarginNote

A handwritten aside in the margin with a drawn arrow: the observant, playful voice that notices what a reader might skip.

**Provide:** the note text (≤10 words, lowercase) and the arrow; place it absolutely beside the thing it points at. `--pencil` for a quieter note, `--flip` to point right-to-left, `--tilt` to angle it.

**Rules**
- In `ink` or `pencil`, never `red-pen`: red is for corrections.
- One per stop, beside a stat, photo or scan, never floating alone.
- On phones it drops below the object it annotates, arrow pointing up.
