# BigStat

A number that carries a claim: a large figure in Barlow Condensed with a plain label, an optional source, and an optional handwritten aside.

**Provide:** the value (unit in `<small>`), a label (≤6 words, sentence case), optional source line in `pencil` and an optional `__pen` aside in Kalam.

**Rules**
- Real numbers only, as precise as they are true: "3,500+", "~200", "₹20,000 in 4–5 hours". No rounded-up vanity numbers, no filler stats.
- In rows of up to three (`.rd-stats`), each with an ink rule on top like a ledger. Two columns on phones.
- `stat` at 132px desktop / 80px phone; `.rd-stats--compact` for supporting numbers.
- The number does the bragging, so the label stays plain. Wit goes in the pen aside.
- Never on the Night stop.
