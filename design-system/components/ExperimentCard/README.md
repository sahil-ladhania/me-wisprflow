# ExperimentCard

An index card for one growth experiment Sahil would run in week one: insight, move, metric, and the condition to kill it.

**Provide:** an id ("EXP 01"), timing and cost meta, a title that states the bet in one line, and the four rows: Insight, The move, I'll measure, I kill it if. The example content shows the shape; the real three come from Sahil.

**Rules**
- Always three cards, never more. Each must name a metric and a kill condition. Kill criteria are what make it read like a growth person, not a fan.
- The kill row's label is `red-pen`: red marks where things can go wrong.
- Insight first, rooted in Indian users' behaviour; no generic "run ads" moves.
- Cards stack on phones with rows collapsing to label-above-text. Desktop: one column of three, slightly offset, as if dealt.
