# StopHeader

The opening of every stop: milestone, kicker, a one-line claim, and the witty aside that undercuts it.

**Provide:** a `Milestone`; a kicker ("STOP 03 · AFTER CLASS 10"); the title (the claim, ≤9 words, `stop-title`); an optional italic lede (`lede`, ≤20 words); the voice chip if the stop has a voice note.

**Rules**
- The title must stand alone: read every title in order and the story still lands. Write it like a headline, not a heading ("Dad's deal: 90% gets the bike.", not "The Bike").
- The lede is where the wit goes. Set up in the title, undercut in the lede.
- On the Night stop, don't use StopHeader at all: use `NightStop`.
- Phones: the milestone moves above the kicker at `--sm` size; title 36px.
