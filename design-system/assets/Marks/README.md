# Marks

- `milestone-mark.svg`: the site's mark. A milestone stone (haldi cap, card body, ink outline) with a voice waveform cut into it: the road and the voice in one shape. Multi-colour; use as is on `paper`, never recolour, never on a dark ground except the Night stop.
- `favicon.svg`: the same mark simplified for 16–32px tabs.
- There is no wordmark. "Sahil" is set in Newsreader 500 wherever a name is needed. Never use the Royal Enfield logo or wordmark.
