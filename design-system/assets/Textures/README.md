# Textures

- `paper-grain.svg`: tiles over `paper` at 100% (it is already ~9% ink). Page background only, not on photos.
- `tape-strip.svg`: masking tape, `tape` colour. The CSS `.rd-tape` draws the same shape; use the file for static exports.
- `pen-strike.svg`, `pen-circle.svg`: red-pen marks in `red-pen` (#b3311b), stretch to fit (`preserveAspectRatio="none"`).
- `road-dash.svg`: one 64px tile of the lane road: `rule` edges, `wave-rest` dash. Repeat-x.
- `ink-bloom.svg`: the irregular blot used as the mask for the ink and smoke transitions. Ink (#17140f).
