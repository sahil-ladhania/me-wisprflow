# Icons

24px grid, 1.75px stroke, round caps and joins. Single ink: `ink` (#17140f). Inline the SVG with `stroke="currentColor"` when it must take another colour (on an ink button it is `paper`).

- `mic.svg`, `mic-off.svg`: the ignition key; mic-off when permission is denied.
- `play.svg`, `pause.svg`: voice notes (filled, so they read at 22px inside a 48px disc).
- `transcript.svg`: "Read it instead" where a text label won't fit.
- `arrow-right.svg`: signboards and "Ride on".
- `scroll-down.svg`: the one hint under the hero after the engine starts.
- `link-out.svg`: external links in the garage.
- `mute.svg`: the engine-sound mute chip.
